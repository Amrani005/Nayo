## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

## Owner dashboard login

Set `OWNER_EMAIL`, `OWNER_PASSWORD`, and an `AUTH_SECRET` of at least 32 characters in the ignored `.env` file. The owner login is available at `/login`; successful sign-in opens `/admin-panel`. Admin routes and product/order management actions require a valid owner session.

Generate a signing secret with:

```powershell
node -e "console.log(require('crypto').randomBytes(32).toString('base64url'))"
```

Restart the development server after editing `.env`.
